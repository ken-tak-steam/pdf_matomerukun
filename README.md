# PDFまとめる君

複数のPDFを、文字・図形・リンクを保持したままひとつにまとめるアプリです。

## 使い方

1. `index.html` をダウンロードし、Chrome・Edge・Safariなどのブラウザで開きます。
2. PDFを複数選択するか、追加欄へドロップします。
3. ページをドラッグ、または左右のボタンで並べ替えます。「×」で削除し、「ひとつ戻す」で復元できます。
4. 必要に応じてページ番号を設定します。表紙・目次が2ページなら、開始するページを3、最初の番号を1に設定します。
5. 「PDFをまとめて保存」を押します。

## オフライン・プライバシー

必要なライブラリ・ワーカー・日本語表示用CMap・フォントデータをHTML内に収録しています。インストール・外部通信は不要です。PDFはメモリ内で処理し、アップロードやブラウザへの永続保存はしません。Content Security Policyでも外部通信を禁止しています。アプリ内の「オフライン用HTMLを保存」で、PDFデータを含まないアプリ単体を保存できます。

## 保持するもの

- 元PDFの文字情報とベクター描画（画像化はプレビューのみ）
- 外部URLへのハイパーリンク
- 出力に残っているページへの文書内リンク（名前付き移動先を含め、並べ替え後に再設定）
- ページサイズ・回転

元から画像のPDFは画像のままで、OCR機能はありません。削除したページや解決できない移動先への文書内リンクは除去し、保存時に件数を表示します。

## ページ番号

左上・上中央・右上・左下・下中央・右下に対応。開始ページ、最初の番号、文字サイズ、余白、黒／グレー、通常／ハイフン／総数付き表示を選択できます。総数は採番対象ページの最終番号です。番号は既存の本文に重ねて追加し、元からある番号は消しません。サムネイルの番号位置・大きさは目安です。

## 制約

パスワード付きPDFは非対応。しおり・電子署名・インタラクティブなフォーム機能は保持対象外です。大容量ファイルは端末メモリによる制限があります。最新ブラウザを使用してください。

## 開発

`ui.html` と `core.js` が編集用ソース、`index.html` が配布用の単独HTMLです。`build.py` は `CODEX_PRIMARY_RUNTIME_NODE_MODULES` 以下の pdf-lib 1.17.1 と pdfjs-dist 5.6.205 を埋め込みます。配布HTML自体にはPythonもNode.jsも不要です。
